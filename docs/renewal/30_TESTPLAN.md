# Test plan: REQ -> TEST -> FX (v2.0.0)

Status: DRAFT-1, 2026-11-09. Binding: R1-R25 (`01_DECISIONS.md`), `10_SPEC.md` DRAFT-2, `20_SHELL.md`, `25_PACKAGING.md`. Gates and scoring: `90_ACCEPTANCE.md`. Every REQ id below is copied from the three specs; this file invents none. Hand-written coverage claims are forbidden (R20): the tables in section 4 are *planned* mappings; actual coverage is generated by `tools/trace.py` from markers + junit.

## 0. ID grammar

| Prefix | Meaning | Runner | Location |
|---|---|---|---|
| `T-<AREA>-nn` | engine test, AREA = REQ area (`GEN SNF TRI CLS SEL PLN CNV RND LKP APR TRX ASM WRT RPT CTR MAP SEC CLI META`) | pytest | `engine/tests/unit|integration|meta/` |
| `CT-nn` | contract test against the *installed* `markitdown-gc` | pytest | `engine/tests/contract/` |
| `JT-nn` | shell test | jest | `shell/test/` |
| `PT-nn` | packaging/CI/release test | pytest (+ shell scripts) | `engine/tests/packaging/`, `.github/` audits |
| `FX-nn` | fixture (section 3) | | `engine/tests/fixtures/` |
| `MAN-nn` | named manual attestation (section 7) | | `attest/*.yml` |
| `S0..S13`, `FM0..FM12`, `K01..K20` | matrix axes (section 5) | | |

Platform rule: a test that cannot run on an OS (e.g. POSIX symlink on unprivileged Windows) carries `@pytest.mark.plat("posix")`; it is *absent* (not skipped) from expected results elsewhere, and each REQ still needs a pass on >= 1 required OS. Any other skip/xfail = failure.

## 2. Traceability mechanism (R20)

1. **Markers.** Engine: `@pytest.mark.req("REQ-XXX-nn", ...)`, plus `@pytest.mark.cov("S<stage>","FM<n>")` (exactly one primary cell), `@pytest.mark.fx("FX-nn", ...)`. Test ID is the function-name prefix `test_T_ASM_06_<slug>` / `test_CT_08_...` / `test_PT_05_...`. Pytest runs with `--strict-markers`; `conftest.py` copies the markers into junit `<property>` entries (`req`, `tid`, `cov`, `fx`, `plat`).
2. **Jest.** Title = `REQ-SHL-02 REQ-SHL-12: JT-02 <description>` (all REQ ids before the first `:`, JT id after). `jest-junit` emits titles; a `req()` helper (`shell/test/req.ts`) asserts the grammar at registration and throws on unknown/duplicate JT ids.
3. **Registry.** Collection (pytest plugin) and `jest --listTests --json` write `build/trace/registry.json`: `{tid, reqs[], cov, fx[], plat}`.
4. **Meta-tests** (`T-META-*`, run first in CI, no Core needed):
   - spec REQ ids = regex over definition lines of `10_SPEC.md`, `20_SHELL.md`, `25_PACKAGING.md` (`^(- )?REQ-[A-Z]+-[A-Za-z0-9]+` followed by MUST/SHOULD/`(deleted`); deleted ids are exempt.
   - FAIL if: a spec REQ has 0 registered tests; a marker names an unknown REQ; a test has no `req` marker; a test id is duplicated or breaks the grammar; a `fx` id is missing from the manifest; a golden file differs from `GOLDEN.lock` or was made by another Core version; a registered `req` set differs from the planned mapping in section 4 (plan may be a subset of marker, never a superset); a matrix cell is neither covered nor declared N/A with a reason.
   - mutation self-test (PT-10): scripted copy of the repo with (a) a marker deleted, (b) an invented REQ id, (c) a fixture removed from the manifest must make `trace.py check` exit non-zero for each.
5. **Results.** `trace.py report` reads junit from the CI matrix (6 engine cells, 3 shell cells, packaging cells). A test is PASS iff it ran and passed on every cell where it is expected; a REQ is COVERED iff >= 1 of its tests is PASS and none FAIL. Output: `trace.json`, `TRACE.md` (REQ -> tests -> status), the two matrices, `SCORE.json`.
6. **Generated MECE matrices** (section 5) come only from markers + `matrix.toml` + fixture manifest.

## 5. Generated MECE matrices

Produced by `tools/trace.py report` into `build/trace/MATRIX_STAGE_FM.md` and `MATRIX_CLASS_STAGE.md`; **never edited by hand**. Inputs: test markers, FX manifest `class`, `engine/tests/matrix.toml` (applicability only).

**Axes.** Stages `S1..S13` = SPEC section 4 (Sniff, Triage, Classify, Select, Convert, Render, Lookup, Plan, Approve, Transcribe, Assemble, Write, Report) + `S0` general (startup, CLI, cancellation, cross-run). Failure modes (primary cause of the injected condition; pick the lowest number that applies, `FM0` if none): `FM0` nominal; `FM1` corrupt/invalid input or internal failure; `FM2` protected/encrypted; `FM3` bound exceeded (bytes, units, pixels, zip, threshold, length); `FM4` unsupported/out-of-scope/legacy; `FM5` local IO/permission failure; `FM6` provider failure; `FM7` interruption/crash/in-flight; `FM8` consent missing/denied/stale; `FM9` hostile or security-relevant input; `FM10` contract/vocabulary/version drift; `FM11` partial coverage/cap/low priority/unmapped; `FM12` duplicate/collision/idempotency/determinism.
File classes `K01..K20`: pdf_text, pdf_scan, pdf_mixed, pdf_capped, raster_single, raster_multiframe, office (docx/pptx/xlsx), hwpx, hwp5, text_g2a, g2b (html/md/epub/xls), legacy, media_audio_video, zip_container, protected, corrupt/zero, oversize, ext_mismatch, unknown_ext, dir_tree.

**Exclusive and exhaustive by construction.** (1) Each engine test has exactly one primary `cov` cell (T-/CT- without a cell fail meta-test). (2) Every cell of the 14x13 stage-FM grid and the 20x14 class-stage grid must be either COVERED (>= 1 passing test) or declared in `matrix.toml` as `N/A` with `reason` and `owner` (the cell that covers it instead); an undeclared empty cell fails `trace.py check`; an N/A cell that is covered is a warning. (3) Class-stage cell = a passing test whose `fx` includes a manifest fixture of that class and whose `cov` stage is that stage.
**Floor (cannot be N/A):** all `S3` x FM0/FM1/FM2/FM3/FM4/FM10/FM11/FM12; `S1:FM1/FM2/FM3/FM9`; `S2:FM1/FM10`; `S6:FM1/FM3`; `S7:FM1/FM5`; `S9:FM8`; `S10:FM6/FM7`; `S12:FM5/FM9`; `S0:FM7/FM10/FM12`; class x `S3` for every class; class x `S11` and `S13` for every class that is not report-only (K12,K13,K15,K16,K17,K19 report-only: `S11` still required because every source gets an entry, GEN-07, only `S11` output may be N/A with reason `report_only`).
